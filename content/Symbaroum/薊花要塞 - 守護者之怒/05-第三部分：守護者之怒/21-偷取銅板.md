# 闖入行動

決定嘗試偷取銅板的角色，很可能會先去旅店踩點。他們可以與員工交談、盯著 3 號房的房門，並摸清進出這棟建築的各種路線。

這幾位兄弟身上沒有任何能揭露他們聖殿騎士身分的標記或徽章。然而，在天坑戰鬥中認出他們的角色就知道他們的底細，因為他們在對抗深淵野獸時並未刻意隱藏自己的神聖力量。如果角色在觀察這幾位兄弟時通過一次【智識】檢定，還會得出結論：他們極可能是貴族——例如從他們的儀態與談吐，更別提他們住得起如此高檔的旅店。

與旅店的客人和員工交談並不會有太大幫助。通過一次【影響】檢定可以打聽到這幾位兄弟何時抵達、其中一人腹部受了重傷，以及另外兩人經常長時間離開旅店。

至於進出路線，當然有沿著樹幹盤旋而上的螺旋階梯。另一個選擇是爬上大樹最低的樹枝，要嘛使用抓鉤（需要抓鉤並通過一次【精準+3】檢定），要嘛從周圍的屋頂跳過去（需要通過一次【敏捷-1】檢定，失敗會從五公尺高處摔落）。

可以從房門（經由走廊）或面向屋後、關上並封好的窗戶進入 3 號房。這兩者都很容易撬開，但需要通過一次【隱匿←察覺】檢定，才不會讓房裡的人察覺闖入並避免遭到突襲。

鼓勵遊戲主持人讓玩家發揮創意。夜間，旅店有兩名守衛（數值同遊騎兵隊長，見《核心規則書》第 212 頁）；只要通過一次【隱匿←察覺】檢定即可避開他們，且因守衛大多數時間都在擲骰子賭博，檢定可獲得 +3 修正。只要他們等到亨-洛安與文哈爾離開旅店，在房裡就不會遇到任何抵抗。沒錯，里奧漢會站起身並拔出長劍，但立刻就會跪倒在地。他除了滿懷怨恨地瞪著他們並呼喊守衛（若先前未被擺平，守衛會在 1d4 回合後趕到）外，什麼也做不了。

當角色一把抓起藏在里奧漢床底下的木箱時，他們立刻就會發現不對勁。箱子是空的！

# 銅板的安息之地

這幾位兄弟將無價的銅板帶進薊花要塞後改變了主意，用毯子將它包好，送到了他們昔日戰友那裡。前聖殿騎士阿拉梅．塞維奧在淨化發現預言的遺跡時，靈魂承受了重創。從那以後，他便退隱到德雷戈家族領地上的一座小農舍裡，就在要塞東邊不遠處。

問題在於，角色要如何得知這件事。最顯而易見的方法當然是逼問里奧漢．梅凱萊。威脅他沒什麼用——他絕不會甘願承認自己知道箱子裡的東西藏在哪裡。然而，如果角色願意告訴他城鎮可能面臨的威脅，他是可以講道理的。倘若角色已經弄清楚自己在尋找什麼，另一個選擇是安排這幾位兄弟與鎮長見面。另一個替代方案則是動用秘術力量與秘術儀式，像是〈扭曲意志〉、〈解讀灰燼〉（兄弟倆曾站在房間的暖爐旁談論阿拉梅的農舍）、〈心靈審訊〉或〈吐真術〉。

要定位這件無價聖物還有一個非常殘酷的辦法：殺掉里奧漢。當他的兄弟們回來發現發生了什麼事時，他們會立刻動身前往農舍，以確保銅板安然無恙。在這種情況下，跟蹤他們是可行的。一如既往，這需要隊伍中〈隱匿〉數值最低的玩家角色通過一次【隱匿←察覺】檢定。

關於銅板下落的唯一真正線索，是一位名叫貝洛拉的年邁醫者。擁有〈治癒〉能力並通過一次【察覺】或【智識】檢定的角色，可以從里奧漢腹部的包紮推斷出一些端倪——敷料裡含有巴塞利昂草，這種草藥在泰坦山脈以北很難生長，但一些活躍於大戰期間的老派醫者仍在使用。只要向旅店員工打聽，就能得知每當有客人需要治療時，通常都會去請一位名叫貝洛拉的婦人。

貝洛拉在瀝青街旁一棟破舊的房子裡開著她那間小小的診所。她已經有點老糊塗了，只要稍微哄騙，很容易就相信如果不把飛翼長柄杓旅店 3 號房病人的情報告訴角色，整座城鎮都會陷入危險。在詳盡交代了里奧漢的傷勢後，她便陷入了冗長的獨白，滔滔不絕地吹捧老安布里托在草藥、食物、風景等各方面有多麼優越。在說了一堆「如果」和「但是」之後，她終於回想起來，當時那名受傷男孩的朋友們在她處理傷口時，曾談論過某件非常重要的事——說什麼一幅畫有危險、說什麼東門外的一座農舍，還有某個叫「阿爾莫還是阿利蒙，不對：阿拉梅！」的人。

城裡多的是人知道，殘陽騎士團的老英雄阿拉梅．塞維奧就定居在要塞附近。角色幾乎可以向任何一位人脈打聽，無論是城鎮衛隊、太陽神教會、祕法學會，還是某些貴族。

# 農舍與騎士們

要不是還有兩名農工在，阿拉梅幾乎就是獨自住在他的農舍裡。亨-洛安與文哈爾每天都會來拜訪幾次，聊聊往日回憶，並確認銅板安全地藏在主屋的地板下。

如果角色已經闖入了他們在旅店的房間，無論里奧漢是死是活，這兩位未受傷的兄弟都會前往阿拉梅那裡。他們會取回寶物，並立刻全速策馬奔向聖殿牆。不過，在亨-洛安與文哈爾發現出了什麼事之前，角色還有一段行動窗口。當角色接近農舍時，讓玩家擲 1d6。結果為 1–2 表示那兩位兄弟正在拜訪；3–6 表示只有阿拉梅與他的農工在場。萬一他們手氣不好擲出前者，當然也可以先等亨-洛安與文哈爾離開（大約兩小時）。

如果只有阿拉梅在場，不經過一場戰鬥他是絕不會交出銅板的，而且直到嚥下最後一口氣前都不會停止戰鬥。他是塊難啃的硬骨頭，而他的農工也會盡力相助。戰鬥開始後，年輕的農工們會從他們的小屋跑出來，並在戰鬥的第三個回合開始用弓箭支援主人。一旦阿拉梅倒下，他們就會拔腿狂奔直到精疲力竭。

如果梅凱萊兄弟當時就在屋裡，戰鬥是可以避免的。但這前提是角色已經與夜幕鎮長談過，並承諾讓他親眼看看並觸摸《薩科馬爾預言》。透過向這幾位兄弟解釋城鎮面臨的威脅，並說服他們這場會面或許是他們帶著銅板活著離開薊花要塞的唯一機會（需要通過一次【影響←堅毅】檢定），他們便可能會考慮達成協議。在所有其他情況下，戰鬥是唯一的途徑。
